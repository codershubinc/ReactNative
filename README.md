

## Navigation

To navigate this repository and find the relevant `README.md` files in each subdirectory, follow these steps:

1. Open the subdirectory of the project you are interested in.
2. Locate the `README.md` file within the subdirectory.
3. Open the `README.md` file to find detailed instructions on how to get started with the respective Expo app, including installing dependencies, starting the app, and accessing various development options.

Each `README.md` file also includes sections on how to reset the project and where to find additional resources for learning more about developing with Expo.

Happy coding!
